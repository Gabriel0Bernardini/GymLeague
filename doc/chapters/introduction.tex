\chapter{Introdução}

O presente documento tem como finalidade apresentar a estrutura, tecnologias e metodologias envolvidas no desenvolvimento do projeto \textbf{GymLeague}, uma aplicação web voltada para o acompanhamento do progresso físico de usuários de academia. 

A plataforma permitirá que o usuário registre seus treinos, monitore a evolução de cargas, compare seu desempenho com outros participantes através de um sistema de ranking e visualize métricas gerais de progresso. 

Este projeto está sendo desenvolvido como parte da disciplina de \textit{Engenharia de Software}, com foco inicial na construção das telas do front-end, seguidas pela implementação do back-end e da integração entre as camadas.

Além disso, o projeto visa aplicar boas práticas de engenharia, como versionamento, modularização de código, documentação técnica e uso de frameworks modernos, de modo a proporcionar uma experiência de desenvolvimento completa e profissional.
