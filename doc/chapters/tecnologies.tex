\chapter{Tecnologias Utilizadas}

Nesta seção são descritas as principais tecnologias e ferramentas empregadas até o momento no desenvolvimento do projeto.

\section{Front-end}
O front-end da aplicação está sendo construído com o \textbf{React} na sua versão mais recente, utilizando o empacotador \textbf{Vite} para inicialização e gerenciamento do ambiente de desenvolvimento. A linguagem escolhida é o \textbf{TypeScript}, devido à sua tipagem estática e maior segurança no desenvolvimento.

\subsection{Principais bibliotecas}
\begin{itemize}
    \item \textbf{React Router DOM}: utilizado para a criação e gerenciamento das rotas de navegação entre as páginas (login, cadastro, perfil, home, etc.);
    \item \textbf{React Hook Form}: responsável pelo controle e validação de formulários de forma performática;
    \item \textbf{Zod}: biblioteca de validação de dados, integrada ao React Hook Form para validações tipadas;
    \item \textbf{TanStack React Query}: gerenciamento de estados assíncronos e cache de requisições HTTP;
    \item \textbf{TailwindCSS}: framework CSS para construção rápida e responsiva de interfaces.
\end{itemize}

\section{Back-end}
O back-end será desenvolvido utilizando o framework \textbf{Flask}, escrito em Python, que permitirá a criação de rotas e endpoints de forma ágil. O Flask será responsável por lidar com autenticação, manipulação de dados e comunicação com o banco de dados.

\section{Banco de Dados}
O Sistema Gerenciador de Banco de Dados (SGBD) ainda está em análise. As principais opções avaliadas são:
\begin{itemize}
    \item \textbf{PostgreSQL}: robusto e adequado para aplicações web escaláveis;
    \item \textbf{SQLite}: leve e ideal para o estágio inicial de desenvolvimento;
    \item \textbf{MySQL}: alternativa amplamente utilizada e de fácil integração;
    \item \textbf{SQLite}: implementado direto no backend.
\end{itemize}

\section{Controle de Versão}
O versionamento do projeto está sendo realizado através do \textbf{Git} e hospedado no \textbf{GitHub}, permitindo o acompanhamento de alterações, controle de branches e colaboração entre os membros do grupo.

\section{IDE e Ferramentas de Desenvolvimento}
A principal IDE utilizada é o \textbf{Visual Studio Code}, configurado com extensões para suporte ao React, TypeScript, formatação de código e integração direta com o GitHub. O Node.js é usado como ambiente de execução e gerenciador de pacotes (\textit{npm}) para o front-end.
